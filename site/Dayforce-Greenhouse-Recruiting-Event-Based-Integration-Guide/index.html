Dayforce / Greenhouse Recruiting Event-Based Integration Guide

← Back to index

This guide applies to the latest public version of the integration (version 2.2.0).

Overview

The Aquera platform allows your organization to scale complex data management by automating data integration across resource types. Aquera's integrations facilitate the automatic provisioning, ensuring consistency across systems. It allows organizations to streamline processes, dynamically scale resources, and automate repetitive tasks, ultimately improving efficiency in managing intricate IT infrastructures and applications.

This outlines how to synchronize candidate and job details between Greenhouse Recruiting and Dayforce. The integration is configured to process Greenhouse Recruiting events for creating or updating employee records in Dayforce and to synchronize job details from Dayforce to Greenhouse Recruiting, ensuring that job information remains up to date across both systems.

Key Functions

The Greenhouse Recruiting to Dayforce event-based integration provides the following functions:

  • Synchronizes hired candidate data from Greenhouse Recruiting to Dayforce.
  • Creates and updates employee records in Dayforce based on candidate information from Greenhouse Recruiting.
  • Synchronizes job data from Dayforce to Greenhouse Recruiting.
  • Creates and updates job records in Greenhouse Recruiting based on Dayforce data.
  • Uploads signed offer letter documents from Greenhouse Recruiting to Dayforce.
  • Generates logs, reports, notifications, and analytics for integration execution.

Prerequisites

The following are the prerequisites:

  • Aquera Tenant Account: You must have a tenant account in the Aquera Admin portal. Visit https://admin.aquera.io to register for a tenant account. Contact your Aquera account manager to get Aquera tenant access.
    Note: If your organization is in the EU region, use the following URL to register: https://admin.eu.aquera.io/
  • Configure the Greenhouse Recruiting Event Listener: You must configure the Greenhouse Recruiting event listener to enable webhook-based event processing. Refer to the Greenhouse Recruiting Event Listener Guide for details.
  • Configure Application Connectors in the Aquera Admin Portal: You need to configure the following application connectors in the Aquera Admin Portal:
    • Greenhouse Recruiting: Refer to the Greenhouse Recruiting Configuration Guide for details.
    • Dayforce: Refer to the Dayforce Configuration Guide for details.

Integration Setup

This section describes how to configure the integration to synchronize candidate data from Greenhouse Recruiting to Dayforce and job data from Dayforce to Greenhouse Recruiting.

Create Integration

Perform the following steps to create the integration:

  1. Log in to the Aquera Admin portal.
  2. Navigate to Integrations from the left side panel.
  3. Click Create Integration.
  4. Search for Dayforce / Greenhouse Recruiting[Event] in the search box next to the Explore Templates section.
  5. Click the integration template to display the Create New Integration pop-up window.
  6. Enter a name and a description for the integration.
  7. Select both application connector instances from the dropdown menus.
  8. Click Continue. The integration configuration page is displayed to configure the integration.

Configuration

The following sections are displayed under the Configuration tab:

Applications

The Applications section displays the source and target application connectors for the integration. This section allows you to search and update these application connectors.

Parameters

The Parameters section enables you to select the integration features required for your use case. It has the following settings:

Integration Scenarios

Configure the following integration scenarios:

  • Enable report-only mode: Enable this option to execute the integration in report-only mode. The report-only mode generates a report to show the data that would be changed without actually making those changes.
  • Enable candidate sync: Enable this option to sync hired candidates from Greenhouse Recruiting into Dayforce as employees. When enabled, the Candidate Configuration section is displayed for configuring additional integration settings. 
  • Enable job sync: Enable this option to sync job data from Dayforce to Greenhouse Recruiting. Whenever a new job is created in Greenhouse, the system will automatically pull matching details from Dayforce and update the job. When enabled, the Job Management section is displayed for configuring additional integration settings.

General Settings

Configure the following general settings:

  • Enable logging: Enable this option to generate logs outlining data changes. When enabled, the Log Settings section is displayed for further configuration.
  • Enable notifications: Enable this option to enable integration-related notifications. When enabled, the Notification Settings section is displayed for further configuration.
  • Enable report generation: Enable this option to generate the integration report. When enabled, the Report Settings section is displayed for further configuration.
  • Enable analytics: Enable this option to visualize the integration-related metrics. When enabled, the Analytics Settings section is displayed for further configuration.

Note: This section appears only if Enable logging is enabled in the General Settings section.

    • GUID with Non-PII Data: Select this option to include GUIDs, operation details, field names, and selected non-PII values.
    • Employee Number with Non-PII Data: Select this option to include employee numbers, operation details, field names, and selected non-PII values.
    • Employee Number with All Data: Select this option to include employee numbers, operation details, field names, and all values, including both PII and non-PII data.
  • Select log detail level: Select the desired log detail level from the dropdown menu. The following are the available options:
    • Full details: All attribute details are displayed.
    • Inclusion list: Select this option to log only the attributes specified in the Custom Inclusion List.
      • Custom inclusion list: Select the attributes to be included in the log insights.
    • Exclusion list: Select this option to log only the attributes specified in the Custom Exclusion List.
      • Custom exclusion list: Select the attributes to be excluded from the log insights.

Candidate Configuration

The Candidate Configuration tab enables you to configure the settings used to synchronize candidate data from Greenhouse Recruiting to Dayforce.

Note: This tab appears only if Enable candidate sync is enabled in the Integration Scenarios section.

Greenhouse Settings

The Greenhouse Settings section enables you to configure the Greenhouse Recruiting events and correlation settings used to synchronize candidate data with Dayforce. It has the following settings:

  • Enable Greenhouse events: Enable this option to trigger employee creation and updates in Dayforce using the selected Greenhouse Recruiting events.
    • Create/update candidate event: Select the Greenhouse Recruiting event that triggers employee creation or updates in Dayforce. When selected, additional configuration options are displayed:
      • Custom attribute for correlation: Select the Greenhouse Recruiting correlation attribute to distinctly find the associated Dayforce employee. For example, Degree. If you do not find your custom attribute in the list, click the refresh icon available next to the field to reload the available attributes.

Dayforce Settings

The Dayforce Settings section enables you to customize the Dayforce settings that control rehire processing and offer letter synchronization. It has the following settings:

  • Inactive statuses to be considered for rehire: Select one or more inactive statuses to be considered for rehire. If you do not find your inactive status in the list, click the refresh icon available next to the field to reload the available statuses. The following are the available options: 
    • ACTIVE: Select this option to treat active employees as eligible for rehire.
    • INACTIVE: Select this status to treat inactive employees as eligible for rehire.
    • TERMINATED: Select this status to treat terminated employees as eligible for rehire.
    • PRESTART: Select this status to treat prestart employees as eligible for rehire.
  • Offer letter title: Enter the title of the offer letter.
  • Offer letter description: Enter the description of the offer letter.
  • Offer letter document type XRefCode: Enter the XRefCode of the document type associated with the offer letter.

Tables

In the Tables tab, you can add tables to the integration. Tables are used to define custom source attributes and synchronize them with the target application. If the required data is not available in the source application, you can define it in a table and use it to update the target application. Once defined, the table can be referenced in attribute mapping expressions to set or update values automatically.

For example, to set the timezone attribute of users in the target application to Europe/Paris, create a table during integration setup with timezone as the attribute name and Europe/Paris as the value. Once defined, reference the table in the source attribute of the attribute mapper using the following format:
TABLE.<table_name>.<key_name> or TABLE.<table_name>[<key_name>]

For example: TABLE.test.timezone

Note: You can configure expressions with nested tables in the attribute mapper, if required.
For example: TABLE.UserHireRecord[TABLE.UserRecord["empDate"]]

Refer to the Using Tables in Integrations guide for more details.

Event

The Event tab enables you to configure the webhook settings used to receive event notifications from Greenhouse Recruiting. These events trigger the integration to create or update employee records in Dayforce based on the configured event settings.

  • Event trigger: Enable this option to process events from Greenhouse Recruiting. When enabled, the Event Source field becomes available for selection.
    • Event source: Select the Greenhouse Recruiting application to use as the event source.
  • URL: Copy this URL and paste it into the appropriate webhook field on the Greenhouse Recruiting Webhooks setup page. For details on setting up a webhook in the Greenhouse Recruiting application, refer to the Set Up Webhooks in Greenhouse Recruiting guide.
  • Refresh Token: Click Refresh Token to generate a new token. Copy the generated token and paste it into the Event Secret field of the Greenhouse Recruiting webhook under the Event Subscription tab on the Demo Application page. For details on setting up a webhook in the Greenhouse Recruiting application, refer to the Set Up Webhooks in Greenhouse Recruiting guide.

For more details, refer to the Greenhouse Recruiting Event Listener Setup Guide.

Update the Integration to the Latest Version

You can upgrade an integration built from a template to the latest version to access new features and enhancements. 

Perform the following steps to upgrade an integration:

  1. Navigate to the Integrations module on the Aquera Admin portal.
  2. Click the vertical ellipsis icon next to an integration and click View Details. The Details panel is displayed with the following sections:
    • INTEGRATION DETAILS: Displays the integration name, description, creation date, last update date, and the user who created or last updated it.
    • TEMPLATE DETAILS: Displays the current version number and its features under CURRENT VERSION. If a newer version is available, the version number and the changes are shown under NEW VERSION AVAILABLE with an Upgrade button.
  3. Click Upgrade. The Upgrade Integration pop-up window is displayed.
  4. Provide the following details for the new integration to be created after the upgrade:
    • New Integration Name: Enter the name of the new integration.
    • Description: Provide a description for the new integration.
      The current version number and the upgraded version number are displayed.
  5. Click Upgrade. A new integration is created with the same configuration details as the existing one, but with features or enhancements from the upgraded version.
