Overview

The Aquera platform enables your organization to scale complex data management by automating data integration across various resource types. Aquera's integrations facilitate automatic provisioning, ensuring consistency across systems. It enables organizations to streamline processes, dynamically scale resources, and automate repetitive tasks, ultimately enhancing efficiency in managing complex IT infrastructures and applications.

In this integration, any users created, updated, or terminated in the selected ITSM application are automatically updated in the selected directory application based on the defined schedule.

By using the HR application as the system of record, the integration enables organizations to automate service desk fulfilment processes throughout the workforce lifecycle, including candidate onboarding, employee onboarding, job changes, leave of absence, termination, and rehire events. The integration supports configurable lifecycle workflows, event-based request generation, automated ticket management, and multi-channel notifications, helping IT and business teams respond efficiently to workforce changes.

 

NOTE: Currently, the supported source applications are Jira Service Management Cloud and ServiceNow, and the supported target applications are Entra ID and Active Directory.

Key Functions

This integration automates service desk processes for lifecycle events with the following capabilities:

  • Identifies workforce lifecycle events from the HR application, including hire, change, leave, termination, and rehire events.
  • Creates service requests or tickets in the configured service desk application based on selected lifecycle events.
  • Supports configurable event timing to create tickets when an event is detected, before the event date, on the event date, or after the event date.
  • Allows custom eligibility rules to control which employee records are included in lifecycle event processing.
  • Automatically updates or closes existing service desk tickets based on configured ticket statuses.
  • Sends event notifications through email and Microsoft Teams.
  • Generates detailed logs, operational reports, and execution summaries.

Prerequisites

The following are the prerequisites:

  • Aquera Tenant Account: You must have a tenant account in the Aquera Admin portal. Visit https://admin.aquera.io to register for a tenant account. Contact your Aquera account manager to get Aquera tenant access.
    Note: If your organization is in the EU region, use the following URL to register: https://admin.eu.aquera.io/
  • Configure Application Connectors in the Aquera Admin Portal: You need to configure the following application connectors in the Aquera Admin Portal:
    • ITSM connector: You must configure a connector for your ITSM application in the Aquera Admin Portal. Refer to the configuration guide for the respective ITSM application for configuration details. For example, Jira Service Management Cloud.
    • Directory connector: You must configure a connector for your directory application in the Aquera Admin Portal. Refer to the configuration guide for the respective directory application for configuration details. For example, Active Directory.

Integration Setup

This section outlines how the integration must be configured to synchronize workforce lifecycle events from an HR application to a service desk application and automate the creation and management of service requests and tickets.

Create Integration

Perform the following steps to create the integration:

  1. Log in to the Aquera Admin portal.
  2. Navigate to Integrations from the left side panel.
  3. Click Create Integration.
  4. Search for Directory / ITSM in the search box next to the Explore Templates section and click it to create a new integration.
  5. Enter a name and a description for the integration.
  6. Click Continue.

Once created, the following tabs are displayed:

  • Overview
  • Directory
  • Service Desk
  • Rules
  • Operations
  • Schedule

This section enables you to specify prompts for generating unique email addresses, Common Names (CNs), User Principal Names (UPNs), and Security Account Manager (SAM) account names.

Click the expand icon () next to the Configure Username Format section to configure the following parameters:

  • Generate Unique Email: Turn on this toggle button to generate a unique email. When turned on, the following parameter is displayed for further configuration.
    • Unique Email Generation Format:
  • Generate Unique CN (Active Directory): Turn on this toggle button to generate a Common Name (CN) for users in the selected directory application. When turned on, the following parameter is displayed for further configuration.

    • Unique CN Generation Format (Active Directory): Enter your prompt for generating the common name. For example, enter the following prompt and click Analyse and Preview:

      Using the Ticket context (First Name, Last Name), generate different unique human-readable Common Name (CN). 
      Rules:
      - Prefer  First Name and Last Name.
      - Remove invalid AD characters: , + " \ ; < > |
      - Format: "<First Name> <Last Name>"
      - Ensure it looks like a person’s full display name.
      - Add a numeric suffix only if needed for uniqueness.
      Return minimum 10 unique CN string.

To view the default name values, turn on the Advanced Preview Options toggle.
      Advanced Preview Options: If you want to test with custom values, turn on the Advanced Preview Options toggle to display the Add Custom Values panel. There, you can enter the first name and last name, and click Refresh Preview. Based on these values and the defined prompt, the generated common name values will appear in the Preview section.

  • Generate Unique UPN: Turn on this toggle button to generate a unique User Principal name (UPN) for users in the selected directory application. When turned on, the following parameter is displayed for further configuration.

    • Unique UPN Generation Format: Enter your prompt for generating the User Principal name (UPN). For example, enter the following prompt and click Analyse and Preview:

    Using the Ticket context (First Name, Last Name), generate a UPN prefix (without @domain).
    Rules:
    - Otherwise build from preferred names: First Name.Last Name.
    - Remove spaces and invalid AD characters.
    - Ensure the prefix is clean, readable, and unique.
    Return minimum 5 UPN prefix string (do not include any domain).

In List View, only configured values are displayed. If you want to modify the configuration, click any value in the row, and it redirects you to the edit mode, where you can make changes.

Schedule

Integrations can be scheduled to run automatically based on your preferred timeframe. Refer to Integration Schedule Setup Guide for further details.

Execute Integration

You can execute an integration manually or schedule it to run automatically. For further details, refer to the User Action on Integrations guide.

Additional Options

Aquera provides additional options in its integration solutions, allowing you to perform various actions on integrations, including executing, upgrading, copying, modifying, deleting, exporting, importing, viewing logs, and downloading reports. Refer to User Actions on Integrations for further details.
