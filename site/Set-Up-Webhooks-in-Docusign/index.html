Set Up Webhooks in Docusign

← Back to index

Overview

When a specific set of events occurs in an application or system, Aquera integrations can process those events and update those changes in a different system or application. The events can be specific data changes in the application, such as creating a new user, creating a new hire, and updating an employee's data. For the application to send those events, you must configure webhooks in the application and specify the set of events for which the notifications have to be sent. When you configure webhooks in that application, you must also specify Aquera's event integration URL to which you want to send those event notifications.

This guide explains the webhook setup in the Docusign application to enable the application to send events to Aquera. After the webhooks setup is completed in Docusign, when a specific event occurs, Docusign sends a JSON payload containing the event details to the Aquera event integration URL configured in the webhooks. Depending on the type of event, the payload data vary.

Aquera integration then processes these events and updates the corresponding data in a target application.

Prerequisites

The following are the prerequisites:

  • Administrator access to the Docusign instance: You must have the Docusign admin credentials.
  • Integration Setup: You must configure an integration in the Aquera Admin portal to process the Docusign events. For details, refer to the Integration Studio Guide.

Set Up Webhooks in Docusign

Perform the following steps to set up Webhooks in Docusign:

  1. Log in to your Docusign instance using the Admin credentials.
  2. Click Admin on the top menu bar.
  3. Click Connect in the side menu bar.
  4. On the Connect (Webhooks) page, click the Add Account Configuration dropdown and select Custom.
  5. On the Add Account Configuration page, enter the following details:
    • Name: Enter a name for the account.
    • URL to Publish: Paste the URL that has been copied from the integration in the Aquera Admin portal. For details, refer to the Obtaining Event URL and Token section.
  6. Scroll down to the Envelope and Recipients section and enable the Employee Signed/Completed event. This will trigger the action when the candidate accepts the offer letter by signing it.

    Note: Whenever any of the enabled events occur, Docusign sends a JSON payload with the event details to the Aquera event-based integration URL.
  7. Scroll down to the Include Data section and select the list of information that you want to include in the JSON file for the integration to process. The following are the minimum required data to be selected:
    • Custom Fields
    • Attachments
    • Recipients
    • Tabs
  8. Scroll down to the Integration and Security Settings section, select the Include Basic Authentication Header checkbox, and enter the following details:
    • Username: Enter a random value that must be used as the username.
    • Password: Paste the token that has been copied from the Aquera event-based integration. For details, refer to the Obtaining Event URL and Token section.
  9. Click Add Configuration.

Obtaining Event URL and Token

After configuring the integration, perform the following steps to obtain the event URL and token from the integration:

  1. Navigate to the Event tab.
  2. Perform the following in the Event tab:
    • Event Trigger Enabled: Turn on the Event Trigger Enabled toggle button to trigger the integration when events occur in Docusign.
    • Event Source: Select the Docusign connector application that you configured for the integration from the dropdown menu.
    • URL: Copy the URL and paste it into the Add Account Configuration page when setting up the webhooks in the Docusign admin portal.
    • Create Token: Click Create Token. A token is generated. Click Save Changes twice to save the configuration, then copy the token and paste it into the Password field on the Add Account Configuration page when setting up webhooks in the Docusign admin portal.
