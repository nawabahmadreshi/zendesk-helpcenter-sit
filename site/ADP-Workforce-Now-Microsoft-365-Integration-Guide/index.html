Overview

The ADP Workforce Now / Microsoft 365 (PTO to Calendar Sync) integration retrieves all workers and their paid time off (PTO) requests from ADP Workforce Now. For PTO requests with an Approved or Active status, the integration creates events in the configured Microsoft 365 shared calendar.

The integration uses each worker's business email address from ADP Workforce Now to locate the shared calendar in Microsoft 365. Each event identifies the PTO policy and worker, and its location is set to Out of Office.

This guide explains how to configure the integration to create Microsoft 365 shared calendar events for qualifying PTO requests retrieved from ADP Workforce Now.

Key Functions

This integration synchronizes PTO information with the following primary capabilities:

  • Retrieves all workers and their PTO requests from ADP Workforce Now.
  • Processes PTO requests with an Approved or Active status only.
  • Uses each worker's business email address to locate available Microsoft 365 calendars.
  • Creates PTO events in the configured Microsoft 365 shared calendar.
  • Includes the PTO policy and worker name in the calendar event subject.
  • Creates an all-day event when the PTO period represents a full day or spans multiple days.

Prerequisites

The following are the prerequisites:

  • Tenant Account in the Aquera Admin Portal: You must have a tenant account with admin access in the Aquera Admin portal. Visit https://admin.aquera.io and register to get a tenant account. Contact your Aquera account manager to get the Aquera tenant access.
    Note: If your organization is in the EU region, use the following URL to register: https://admin.eu.aquera.io/.
  • ADP Workforce Now Application Connector in the Aquera Admin Portal: You need to configure an ADP Workforce Now application connector in the Aquera Admin portal. The connector must have access to retrieve workers and PTO requests.
  • Microsoft 365 Application Connector in the Aquera Admin Portal: You need to configure a Microsoft 365 application connector in the Aquera Admin portal. The connector must have access to retrieve user calendars and create calendar events.
  • Worker Email Address: Each worker in ADP Workforce Now must have a business email address that corresponds to the worker's Microsoft 365 email address or user principal name.
  • Shared Calendar Access: The shared calendar must be available to the applicable Microsoft 365 users. The configured Microsoft 365 connector must have permission to create events in the calendar.
  • Shared Calendar Owner: You must have the email address or user principal name of the shared calendar owner.

Integration Setup

This section details the configuration process for synchronizing PTO requests from ADP Workforce Now to a Microsoft 365 shared calendar. It outlines the steps to create the integration, select the application connectors, and configure the shared calendar.

Create Integration

Perform the following steps to create the integration:

  1. Log in to the Aquera Admin portal.
  2. Navigate to Integrations from the left side panel.
  3. Click Create Integration.
  4. Search for ADP Workforce Now / Microsoft 365 in the search box next to the Explore Templates section, and then select it to create a new integration.
  5. Enter a name and a description for the integration.
  6. Select the ADP Workforce Now and Microsoft 365 application connectors.
  7. Click Continue.

Once created, the following tabs are displayed:

  • Configuration
  • Schedule

Configuration

The Configuration tab shows the application connectors used for the integration and allows you to configure the Microsoft 365 shared calendar.

The following sections are displayed in this tab for configuration:

  • Applications
  • Parameters

Applications

This section allows you to select the application connectors used for the integration. The following fields are displayed:

  • Microsoft Entra ID: Identifies the Microsoft 365 application connector that you have configured in the Aquera Admin portal. If you do not find your application connector in the list, click the refresh icon next to the field to reload the available connectors.
  • ADP Workforce Now: Identifies the ADP Workforce Now application connector that you have configured in the Aquera Admin portal. If you do not find your application connector in the list, click the refresh icon next to the field to reload the available connectors.

Parameters

This section allows you to select the Microsoft 365 shared calendar in which PTO events are created. The following fields are displayed:

  • Shared Calendars: Select the Microsoft 365 shared calendar in which PTO events must be created. If you do not find the calendar in the list, click the refresh icon next to the field to reload the available calendars.

  • Owner Email: Enter the email address or user principal name of the shared calendar owner.

    Note: The integration identifies the shared calendar using the selected calendar name and the configured owner. Ensure that both values identify the intended calendar.

Schedule

Integrations can be scheduled to run automatically based on your preferred timeframe. Navigate to the Schedule tab to configure the integration execution schedule based on how frequently PTO changes must be reflected in Microsoft 365.

Refer to the Integration Schedule Setup Guide for further details.
