Overview

Aquera provides an innovative platform that enables organizations to automate data synchronization between Dayforce and Microsoft Dynamics 365 Finance & Operations, helping maintain consistent employee and organizational data across systems.

Aquera's integrations facilitate automatic synchronization, allowing organizations to streamline data management processes and reduce manual effort.

The Dayforce to Dynamics 365 Finance & Operations integration facilitates the synchronization of Employees, Departments, Jobs, and Positions from Dayforce to Dynamics 365 Finance & Operations based on the configured integration setup. When records are created or updated in Dayforce, the corresponding records are synchronized with Dynamics 365 Finance & Operations.

The integration also supports manager position hierarchy, allowing manager relationships to be maintained based on the configured position hierarchy.

Prerequisites

The following are the prerequisites:

  • Aquera Tenant Account: You must have a tenant account in the Aquera Admin portal. Visit https://admin.aquera.io and register to get a tenant account. Contact your Aquera account manager to get Aquera tenant access.
    Note: If your organization is in the EU region, use the following URL to register: https://admin.eu.aquera.io/ 
  • Configure Applications in the Aquera Admin Portal: 
    • Dayforce Connector: Ensure you add and configure the Dayforce connector in the Aquera Admin portal. For details, refer to the corresponding Dayforce Configuration Guide.
    • Dynamics 365 Finance and Operations connector: Ensure you add and configure the Dynamics 365 Finance and Operations connector in the Aquera Admin portal. For details, refer to the corresponding Microsoft Dynamics 365 Finance and Operations Configuration Guide. 

Integration Setup

Perform the following steps to create the integration:

  1. Log in to the Aquera Admin portal.
  2. Navigate to Integrations on the left panel.
  3. Click Create Integration.
  4. Search for Dayforce / Dynamics 365 Finance and Operations in the search box next to the Explore Templates section, and click it. The Create New Integration pop-up window is displayed.
  5. Enter a name and a description for the integration.
  6. Select the source and target applications.
  7. Click Continue.

Manager Assignment Settings

This section allows you to configure the manager hierarchy used to assign an active manager to the user. This section is displayed only when Enable Manager Position Assignment toggle is enabled.

  • Max Manager Hierarchy Depth: Enter the maximum number of hierarchy levels that the integration must check to find an active manager to whom the user can be assigned.
    For example: if you enter 3, the integration checks up to three levels in the hierarchy. If the direct manager is active, the user is assigned to that manager. If not, the integration checks the next level. If an active manager is found within the three specified levels, the user is assigned to that manager. Otherwise, no manager is assigned to the user.
  • Fallback Manager Action: Select the action to perform when an active manager is not found within the specified hierarchy levels. The following options are available:
    • Leave Unassigned: Select this option to leave the user without an assigned manager.
    • Use Default Manager: Select this option to assign the user to the default manager.
      • Fall Back Manager Personnel Number: Enter the personnel number of the default manager to whom the user must be assigned.
    • Assign to Admin: Select this option to assign the user to the admin.
      • Admin Personal Number: Enter the personal number of the admin to whom the user must be assigned.

Attribute Map

Tables

Tables can be added to create custom source attributes and POST (sync) them to the target application. Tables are used when an application attribute is empty or a specific data is not sent from the HR application, and you want to update a value for that attribute in the directory. Based on your requirement, you can add any number of tables in the integration.

The table setup and functionality are the same as that in the User Integration. Refer to the Adding Tables in Integration section in the Using Tables in Integration guide for details.
