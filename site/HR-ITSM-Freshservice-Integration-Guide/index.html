Overview

The Aquera platform enables your organization to scale complex data management by automating data integration across various resource types. Aquera's integrations facilitate automatic provisioning, ensuring consistency across systems. It enables organizations to streamline processes, dynamically scale resources, and automate repetitive tasks, ultimately enhancing efficiency in managing complex IT infrastructures and applications.

This integration connects your HCM system with the supported ITSM application to automate identity-driven workflows across the employee lifecycle. It creates and manages ITSM tickets for workforce events such as joiners, movers, leavers, rehires, leaves of absence, and role or profile changes. The integration also supports access fulfillment(entitlement-driven ticketing), manual fulfillment(ticket-driven provisioning), asset management, organizational object synchronization, and employee profile synchronization to streamline IT service management processes. The Service Desk Bridge and HCM Bridge modules can be configured independently to meet your organization's deployment requirements.

Key Functions

This integration automates Freshservice request creation for employee lifecycle events with the following primary capabilities:

  • Retrieves workforce data from the configured HR application.
  • Detects employee lifecycle events based on configured rules.
  • Creates Freshservice tickets for selected employee lifecycle events.
  • Allows custom employee matching between the HR application and Freshservice.
  • Maps HR attributes to Freshservice request fields.
  • Supports configurable rules to determine when employee lifecycle events are processed for ticket creation.
  • Sends event notifications through email.
  • Generates detailed logs, operational reports, and execution summaries.

Prerequisites

The following are the prerequisites:

  • Aquera Tenant Account: You must have a tenant account in the Aquera Admin portal. Visit https://admin.aquera.io to register for a tenant account. Contact your Aquera account manager to get Aquera tenant access.
    Note: If your organization is in the EU region, use the following URL to register: https://admin.eu.aquera.io/.
  • Configure Application Connectors in the Aquera Admin Portal: You need to configure the following application connectors in the Aquera Admin Portal:
    • HR Application Connector: You must configure a connector for your HR application in the Aquera Admin Portal. Refer to the configuration guide for the respective HR application for configuration details. For example, if Dayforce is your HR application, refer to the Dayforce Configuration Guide for details.
    • Freshservice Connector: You must configure the Freshservice Connector in the Aquera Admin portal. Refer to the Freshservice Configuration Guide for details.

Integration Setup

Create Integration

Perform the following steps to create the integration:

  1. Log in to the Aquera Admin portal.
  2. Navigate to Integrations from the left side panel.
  3. Click Create Integration.
  4. Search for HR / ITSM - Freshservice in the search box next to the Explore Templates section and click it to create a new integration.
  5. Enter a name and a description for the integration.
  6. Click Continue.

Once created, the following tabs are displayed:

  • Overview
  • Features
  • Source
  • Service Desk
  • Operations
  • Tables
  • Schedule

Overview

The Overview tab displays general information about the integration, including its purpose and supported capabilities. It provides a high-level overview of how the integration automates employee lifecycle request creation between the HR application and Freshservice.

Source

The Source tab allows you to identify the HR application used by the integration and define how employee lifecycle events are processed.

The following sections are available on this tab:

  • Application Settings
  • Filter 

Application Settings

The Application Settings section allows you to identify the HR application instance used by the integration. The following field is available in this section for configuration:

  • Source application instance: Select the HR application connector from which employee data and lifecycle events will be retrieved for this integration. If the required connector is not available in the list, click the refresh icon next to the field to reload the available connectors.

Employee Lifecycle / Source Filter

The Employee Lifecycle section allows you to configure how employee lifecycle events are processed by the integration. The following field is available in this section for configuration:

  • Enable User Management / Enable employee filter: Turn on this toggle button to filter employees from the source system. Only employees who match the filter criteria are considered for Jira Service Management ticket creation. When enabled, the User Lifecycle Configuration / Employee Filter Configuration section is displayed for further configuration.

User Lifecycle Configuration / Employee Filter Configuration

This section allows you to configure the criteria used to filter employees from the source system for Jira Service Management ticket creation.

The following fields are displayed for configuration:

  • Use Custom Rules for Employee Account Creation / Use filter for new hires: Turn on this toggle button to filter new hires from the source system. Only new hires who match the filter criteria are considered for Jira Service Management ticket creation.
    When enabled, the following fields are displayed for configuration:
    • Create Accounts Based On / Employee filter Criteria: Select the method used to filter employees from the source system. The following is the available option:
      • Based on date: Select this to filter employees using a date attribute from the source system. Only matching employees are considered for ticket creation.
    • Date to Trigger Account Creation / Date attribute to filter employees: Select the date attribute used to filter employees from the source system. For example, select Hire Date.
    • Hire Employee Look Back (Days) / Employee filter lookback period (days): Enter the number of past days to consider when filtering new hires.
  • Use Custom Rules for Account Termination / Use filter for terminated employees: Turn on this toggle button to filter terminated employees from the source system. Only terminated employees who match the filter criteria are considered for Jira Service Management ticket creation.
    When enabled, the following fields are available for configuration:
    • Terminate Accounts Based On / Employee filter criteria: Select the method used to filter terminated employees from the source system. The following is the available option:
      • Based on date: Select this to filter terminated employees using a date attribute from the source system. Only matching employees are considered for ticket creation.
    • Date Attribute for Account Termination / Date attribute to filter employees: Select the date attribute used to filter terminated employees from the source system. For example, select Termination Date.
    • Terminate Look Back (Days) / Employee filter lookback period (days): Enter the number of past days to consider when filtering terminated employees from the source system.
