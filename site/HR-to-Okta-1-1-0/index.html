This guide applies to integration version 1.1.0.

Prerequisite component

  • Custom Identity Source: You must configure a custom identity source in your Okta application. For more information, refer to the Custom Identity Source Configuration section in the Okta Initial Setup Guide.

Integration Execution

  • Integration Sync Mode: The following options are available:
    • Aquera Manage: Select this option to update the user directory attributes.
    • Okta Manage: Select this option to update the Custom Identity Source application attributes.

Aquera Manage

Auto-Create and Map Attributes in Okta Application: If the Auto-Create and Map Attributes in Okta Application toggle is enabled, the integration automatically creates and maps the missing attribute values in your Custom Identity Source application. Only the attributes for which an expression has been configured in the Attribute Mapper are created and mapped.

If the Auto-Create and Map Attributes in Okta Application toggle is disabled, you must manually create and map the missing attributes in the Custom Identity Source application. 

 
If the Auto-Create and Map Attributes in Okta Application toggle is enabled, the missing attributes for which an expression has been configured in the Attribute Map are automatically created and mapped in the Custom Identity Source application.
 
Turn on the toggle button to automatically create and map the missing attribute values in the Custom Identity Source application. Only the attributes for which an expression has been configured in the Attribute Map are automatically created and mapped.
 
For example: If the Manager attribute does not exist in the Custom Identity Source application and an expression is configured for it in the Attribute Mapper, when the toggle button is enabled, the Manager attribute is automatically created and mapped in the application.

Note: This toggle button is visible only when Aquera Manage is selected in the Integration Sync Mode field in the Connection tab.

Okta Manage

Okta Manage enables you to update Custom Identity Source application attributes. To use this feature, you must first configure a Custom Identity Source in your Okta application.

Onboarding

In the Bulk Upsert section, you can create new records and update existing records. Enter a JavaScript expression in the Upsert Expression field to determine whether to perform bulk update or insert operations. 
The following are a few sample values:
  • SOURCE.active==true: Considers users whose active attribute is set to true in the source application. 
  • true: Considers all users whose active attribute is set to true or false in the source application. 
  • false: Ignores the upsert operation.

Offboarding

In the Bulk Delete section, you can delete multiple records at a single time based on the JavaScript expression provided in the Delete Expression field. Enter a JavaScript expression in the Delete Expression field to determine whether the bulk delete operation should be performed.
The following are a few sample values:

  • SOURCE.active==true: Considers users whose active attribute is set to true in the source application. 
  • true: Considers all users whose active attribute is set to true or false in the source application. 
  • false: Ignores the delete operation.

In the Bulk Delete section, you can delete multiple records at a single time. Provide the JavaScript expression in the Delete Expression field, the expression determines whether to perform a bulk delete operation.
