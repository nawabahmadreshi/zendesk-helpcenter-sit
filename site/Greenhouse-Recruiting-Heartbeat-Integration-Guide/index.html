Greenhouse Recruiting Heartbeat Integration Guide

← Back to index

Overview

Aquera’s Greenhouse Recruiting Heartbeat integration makes scheduled calls through the Greenhouse Recruiting connector to refresh its authentication tokens automatically to keep the token active.

The Greenhouse Recruiting connector requires reauthorization if its refresh token expires after 24 hours of inactivity. The heartbeat integration helps prevent this interruption by keeping the token active even when other integrations are not running.

This guide explains how to configure the Greenhouse Recruiting Heartbeat integration to run on a schedule and reduce the need for manual reauthorization.

Prerequisites

The following are the prerequisites:

  • Tenant Account in the Aquera Admin Portal: You must have a tenant account with admin access in the Aquera Admin Portal. Visit https://admin.aquera.io and register to get a tenant account. Contact your Aquera account manager to get Aquera tenant access.
    Note: If your organization is in the EU region, use the following URL to register: https://admin.eu.aquera.io/.
  • Greenhouse Recruiting Application Connector in the Aquera Admin Portal: You need to configure the Greenhouse Recruiting application connector in the Aquera Admin portal. Refer to the Greenhouse Recruiting Configuration Guide for configuration details.

Integration Setup

This section outlines the steps to create the integration and set up the execution schedule.

Create Integration

Perform the following steps to create the integration:

  1. Log in to the Aquera Admin Portal.
  2. Navigate to Integrations from the left-side panel.
  3. Click Create Integration.
  4. Search for Greenhouse Recruiting Heartbeat in the search box next to the Explore Templates section, and then select it to create a new integration.
  5. Enter a name and a description for the integration.
  6. Select your Greenhouse Recruiting instance.
  7. Click Continue. The Configuration page is displayed to configure the integration.

Configuration

On the Configuration page, the following section is displayed:

Applications

The Applications section displays the application connectors selected for the integration. You can search for and update the application connector.

Schedule

You can schedule the integration to run automatically at your preferred interval, such as every 4 hours. Refer to the Integration Schedule Setup Guide for further details.

Note: Ensure that the interval between executions is less than 24 hours to prevent token expiration.

Execute Integration

You can execute an integration manually or schedule it to run automatically. For further details, refer to the User Action on Integrations guide.
