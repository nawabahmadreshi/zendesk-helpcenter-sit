ADP Workforce Now / Homecare Homebase Integration Guide

← Back to index

This guide applies to the latest public version of the integration (version 1.3.0).

Overview

The Aquera platform allows your organization to scale complex data management by automating data integration across resource types. Aquera's integrations facilitate automatic provisioning, ensuring consistency across systems. It allows organizations to streamline processes, dynamically scale resources, and automate repetitive tasks, ultimately improving efficiency in managing intricate IT infrastructures and applications.

In this integration, user records that are created, updated, or terminated in ADP Workforce Now are automatically provisioned in Homecare Homebase based on the defined schedule. The integration evaluates each user's employment status in ADP Workforce Now, determines whether the corresponding Homecare Homebase profile must be created, updated, or deactivated.

To identify user records across both systems, the integration uses the attribute configured in the ADP Workforce Now Correlation Attribute parameter and matches it to the attribute configured in the HCHB Correlation Attribute parameter as a correlation attribute.

Key Functions

The ADP Workforce Now / Homecare Homebase Integration performs the following functions:

  • Synchronizes user records from ADP Workforce Now to Homecare Homebase.
  • Creates new user profiles in Homecare Homebase when a user is added and becomes active in ADP Workforce Now.
  • Sends a welcome email to newly provisioned Homecare Homebase users with their generated username and temporary password.
  • Updates existing Homecare Homebase user profiles when the corresponding user's information changes in ADP Workforce Now.
  • Deactivates Homecare Homebase user profiles when a user becomes inactive or is terminated in ADP Workforce Now.
  • Schedules a user's deactivation to a configured time of day, optionally evaluated in the user's own time zone, and automatically re-evaluates deferred deactivations on every subsequent run until they become due.
  • Sends success and failure notification emails to administrators, optionally with a CSV integration report attached.
  • Supports both full synchronization and incremental synchronization to process only changed records.

Integration Setup

This section outlines how the integration must be configured to provision user data from ADP Workforce Now into Homecare Homebase.

Create Integration

Perform the following steps to create the integration:

  1. Log in to the Aquera Admin portal.
  2. Navigate to Integrations from the left-side panel.
  3. Click Create Integration.
  4. Select ADP Workforce Now / Homecare Homebase.
  5. Enter a name and a description for the integration.
  6. Select your ADP Workforce Now and Homecare Homebase connector instances.
  7. Click Continue. The Configuration page is displayed to configure the integration.

Configuration

On the Configuration page, the following sections are displayed:

Applications

The Applications section displays the source and target application connectors for the integration. This section allows you to search and update these application connectors.

Parameters

The Parameters section enables you to customize the integration features and general settings according to your specific use case.

Integration Features

Enable the following feature based on your requirements:

  • Enable User Lifecycle Management: Select this checkbox to synchronise user data from ADP Workforce Now to Homecare Homebase. When selected, the Manage Users tab is displayed for further configuration.

General Settings

Configure the following settings:

  • Enable Full Sync: Select this checkbox to execute the integration in full sync mode. When selected, the parameter below is displayed for further configuration. If the checkbox is not selected, the integration executes in incremental import mode and processes only user records that have been created or modified since the last successful execution.
    • Full Sync Threshould In days: Enter the number of days after which a full synchronization is automatically triggered. For example, if you enter 4 in this field, the integration will be executed every four days.
  • Enable Report-Only Mode: Select this checkbox to execute the integration in the report-only mode. The report-only mode generates a report to show the data that would be changed without actually making those changes.
  • Enable Logging: Select this checkbox to generate logs outlining data changes. When enabled, the Logging section is displayed for further configuration.
  • Enable Notifications: Select this checkbox to enable integration-related notifications. When enabled, the Notification section is displayed for further configuration.
  • Enable Report Generation: Select this checkbox to generate the integration report. When enabled, the Reporting section is displayed for further configuration.
  • Enable Log Insights: Select this checkbox to visualize the integration-related metrics. When enabled, the Log Insights section is displayed for further configuration.
  • Enable Debug Mode: Select this checkbox to generate logs outlining data changes that would occur, for debugging purposes. When enabled, the Debug Mode section is displayed for further configuration.

Manage Users

The Manage Users section enables you to customize the integration settings for user management according to your specific use case.

ADP Workforce Now Settings

Configure the following ADP Workforce Now settings to specify which users should be considered for synchronization:

Note: All parameters marked with a red asterisk (*) are mandatory.

  • ADP Workforce Now Correlation Attribute*: Select the ADP Workforce Now attribute used to distinctly find the associated Homecare Homebase user record. For example, select WorkerID.
  • ADP Workforce Now Active Statuses: Select one or more ADP Workforce Now user status values to be treated as active. For example, if you select Active and Leave, users with these statuses are considered active. Only users with these statuses are eligible for creation or update in Homecare Homebase.
  • ADP Workforce Now Inactive Statuses: Select one or more ADP Workforce Now user status values to be treated as inactive. For example, if you select Terminated and Retired, users with these statuses are considered inactive. Only users with these statuses are eligible for deactivation in Homecare Homebase.

    Note: The same status value cannot be configured as both active and inactive. The integration validates this and stops with an error if a duplicate is found.

HCHB Settings

Configure the following Homecare Homebase correlation parameter setting:

  • HCHB Correlation Attribute: Select the Homecare Homebase attribute used to distinctly find the associated ADP Workforce Now user. For example, PayrollNumber.

User Provisioning Settings

This section enables you to select the user provisioning operations that must be performed in HCHB.

  • Enable Create: Select this option to create the users in the Homecare Homebase from ADP Workforce Now. When selected, the Create User Settings section is displayed for further configuration.
  • Enable Update: Select this option to update the users in the Homecare Homebase from ADP Workforce Now. When selected, the Update User Settings section is displayed for further configuration.
  • Enable Terminate: Select this option to terminate the users in the Homecare Homebase from ADP Workforce Now. When selected, the Terminate User Settings section is displayed for further configuration.

Create User Settings

Configure the following settings to define the limits and conditions for specifying which users should be considered for creation in Homecare Homebase from ADP Workforce Now.

  • Create User Limit: Enter the maximum number of user records that can be created in Homecare Homebase from ADP Workforce Now during a single integration run. For example, if you enter 10, only the 10 user records that satisfy the condition provided in the Create Condition parameter will be created.
  • Create Condition: Select a condition from the dropdown menu to determine when users must be created in Homecare Homebase from ADP Workforce Now. The following are the available options:
    • All Active Users: Select this option to create all active users from ADP Workforce Now in Homecare Homebase.
    • Custom: Select this option to define a custom condition for creating user records in Homecare Homebase from ADP Workforce Now. Only user records that satisfy this condition will be created in Homecare Homebase from ADP Workforce Now.
      • Custom Create Condition: Enter a JavaScript expression that defines the create condition.

Update User Settings

Configure the following settings to define the limits and conditions for specifying which users should be considered for updating in Homecare Homebase from ADP Workforce Now.

Note: All parameters marked with a red asterisk (*) are mandatory.

  • Update User Limit: Enter the maximum number of user records that can be updated in Homecare Homebase from ADP Workforce Now during a single integration run. For example, if you enter 8, only the 8 user records that satisfy the condition provided in the Update Condition parameter will be updated.
  • Update Condition*: Select a condition from the dropdown menu to determine when users must be updated in Homecare Homebase from ADP Workforce Now. The following are the available options:
    • All Active Users: Select this option to update all active users from ADP Workforce Now in Homecare Homebase.
    • Custom: Select this option to define a custom condition for updating user records in Homecare Homebase from ADP Workforce Now. Only user records that satisfy this condition will be updated in Homecare Homebase from ADP Workforce Now.
      • Custom Update Condition: Enter a JavaScript expression that defines the update condition.

Terminate User Settings

Configure the following settings to define the limits and conditions for specifying which users should be considered for termination in Homecare Homebase from ADP Workforce Now.

  • Terminate User Limit: Enter the maximum number of user records that can be terminated in Homecare Homebase from ADP Workforce Now during a single integration run. For example, if you enter 2, only the 2 user records that satisfy the condition provided in the Terminate Condition parameter will be terminated.
  • Time for terminating a user: Enter the time of day, in HH:MM:SS format, at which a user's Homecare Homebase record becomes eligible for termination on or after their ADP Workforce Now termination date. If this field is left blank, deactivation is not time-gated and proceeds as soon as the user is identified as inactive.
  • Terminate based on users timezone: Turn on this toggle button to terminate the user in the user's own time zone. The user's time zone is determined from their primary work assignment's time profile, home work location, or, if neither is available, the U.S. state associated with their home work location.
  • Terminate Condition: Select a condition from the dropdown menu to determine when users must be terminated in Homecare Homebase from ADP Workforce Now. The following are the available options:
    • All Inactive Users: Select this option to delete all the inactive users from ADP Workforce Now in Homecare Homebase.
    • Custom: Select this option to define a custom condition for deleting user records in Homecare Homebase from ADP Workforce Now. Only user records that satisfy this condition will be deleted in Homecare Homebase from ADP Workforce Now.
      • Custom Terminate Condition: Enter a JavaScript expression that defines the delete condition.

Note: If a user's termination date and time have not yet been reached, the user is not terminated and is skipped for that run with the reason Termination deferred. The integration automatically rechecks these users on every subsequent run and terminates them once the configured time is reached.

Attribute Map

The Attribute Map tab defines how data is mapped from the source to the target application. The default mapping of attributes is displayed on the page. The source attributes are listed on the left side and the target attributes are listed on the right side of the page.

You can modify only the source attributes as needed, to align with your specific use case.

You can write JavaScript expressions to modify the value of the source attribute and construct a value to be updated in the target attribute. Write the expression directly in the source attribute field or click the Expand icon in the source attribute field to write a long-expression.

Tables

Tables can be added to create custom source attributes and POST (sync) them to the target application. Tables are used when an application attribute is empty or a specific data is not sent from the ADP Workforce Now application, and you want to update a value for that attribute in Homecare Homebase. Based on your requirement, you can add any number of tables in the integration.

The table setup and functionality are the same as that in the User Integration. Refer to the Adding Tables in Integration section in the Using Tables in Integrations guide for details.

Update the Integration to the Latest Version

You can upgrade an integration built from a template to the latest version to access new features and enhancements.

Perform the following steps to upgrade an integration:

  1. Navigate to the Integrations module on the Aquera Admin portal.
  2. Click the vertical ellipsis icon next to an integration and click View Details. The Details panel is displayed with the following sections:
    • INTEGRATION DETAILS: Displays the integration name, description, creation date, last update date, and the user who created or last updated it.
    • TEMPLATE DETAILS: Displays the current version number and its features under CURRENT VERSION. If a newer version is available, the version number and the changes are shown under NEW VERSION AVAILABLE with an Upgrade button.
  3. Click Upgrade. The Upgrade Integration pop-up window is displayed.
  4. Provide the following details for the new integration to be created after the upgrade:
    • New Integration Name: Enter the name of the new integration.
    • Description: Provide a description for the new integration.
      The current version number and the upgraded version number are displayed.
  5. Click Upgrade. A new integration is created with the same configuration details as the existing one, but with features or enhancements from the upgraded version.
