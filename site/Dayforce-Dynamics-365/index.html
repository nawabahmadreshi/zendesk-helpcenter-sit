Overview

Prerequisites

The following are the prerequisites:

  • Aquera Tenant Account: You must have a tenant account in the Aquera Admin portal. Visit https://admin.aquera.io and register to get a tenant account. Contact your Aquera account manager to get Aquera tenant access.
    Note: If your organization is in the EU region, use the following URL to register: https://admin.eu.aquera.io/ 
  • Configure Applications in the Aquera Admin Portal: 
    • Dayforce Connector: Ensure you add and configure the Dayforce connector in the Aquera Admin portal. For details, refer to the corresponding Dayforce Configuration Guide.
    • Microsoft Dynamics 365 connector: Ensure you add and configure the Microsoft Dynamics 365 connector in the Aquera Admin portal. For details, refer to the corresponding

Integration Setup

Perform the following steps to create the integration:

  1. Log in to the Aquera Admin portal.
  2. Navigate to Integrations on the left panel.
  3. Click Create Integration.
  4. Search for Dayforce / Dynamics 365 in the search box next to the Explore Templates section, and click it. The Create New Integration pop-up window is displayed.
  5. Enter a name and a description for the integration.
  6. Select the source and target applications.
  7. Click Continue.

Configuration

The Configuration tab includes a list of configurations required to set up the integration. The following sections are available under this tab:

  • Applications
  • Parameters
  • Logging Settings
  • Reporting Settings
  • Notification Setting
  • Log Insights Setting

Applications

The Applications section allows you to select the Dayforce connector and the Dynamic 365 Finance connector that are used by the integration. The following fields are displayed:

  • Dayforce: Select the Dayforce application from which the integration retrieves the data.
  • Dynamic 365 Finance: Select the Dynamic 365 application from which the integration retrieves the data.
