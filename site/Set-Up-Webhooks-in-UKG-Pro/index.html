Overview

When a specific set of events occurs in an application or system, Aquera integrations can process those events and update those changes in a different system or application. The events can be specific data changes in the application, such as creating a new user, creating a new hire, and updating an employee's data. For the application to send those events, you must configure webhooks in the application and specify the set of events for which the notifications have to be sent. When you configure webhooks in that application, you must also specify Aquera's event integration URL to which you want to send those event notifications.

This guide explains the webhook setup in the UKG Pro application to enable the application to send events to Aquera. After the webhooks setup is completed in UKG Pro, when a specific event occurs, UKG Pro sends a JSON payload containing the event details to the Aquera event integration URL configured in the webhooks. Depending on the type of event, the payload data vary.

Aquera integration then processes these events and updates the corresponding data in a target application.

Prerequisites

The following are the prerequisites:

  • Administrator access to the UKG Pro webhooks portal: You must have the admin credentials (username and password) of the UKG Pro webhooks portal.
  • Integration Setup: You must set up an integration in the Aquera Admin portal to process the UKG Pro events. For details, refer to the Integration Studio Guide.

Set Up Webhooks in UKG Pro

Perform the following steps to set up Webhooks in UKG Pro:

  1. Go to the UKG Pro Webhooks portal in your browser using the URL for your region.
    • For US HCM and WFM customers, enter https://webhooks.ukg.net.
    • For Canadian customers, enter https://webhooks-ca.ukg.net.
    • For WFM EU, enter https://webhooks-eu.ukg.net.
    • For WFM AU, enter https://webhooks-au.ukg.net.
  2. Enter the company access code. For details on creating the company access code, refer to the Creating Company Access Code section.
  3. Select Next.
  4. Enter your username and password.
  5. Select Sign In.
