Overview

The Aquera platform enables your organization to scale complex data management by automating data integration across various resource types. Aquera's integrations facilitate automatic provisioning, ensuring consistency across systems. It enables organizations to streamline processes, dynamically scale resources, and automate repetitive tasks, ultimately enhancing efficiency in managing complex IT infrastructures and applications.

This integration automates identity-driven IT service management workflows by connecting your UKG Ready with Zendesk. The integration retrieves workforce data from the selected HR application, detects employee lifecycle events based on the configured lifecycle rules, and automatically creates Zendesk tickets for the configured lifecycle events.

The integration supports configurable ticket creation for employee lifecycle events, such as new hires and terminations. It also allows you to control when tickets are created, map employee information to Zendesk request fields, and customize how employees are matched between the HR system and Zendesk.

Key Functions

This integration automates Zendesk request creation for employee lifecycle events with the following primary capabilities:

  • Retrieves workforce data from the configured HR application.
  • Detects employee lifecycle events based on configured rules.
  • Creates Zendesk tickets for selected employee lifecycle events.
  • Allows custom employee matching between the HR application and Zendesk.
  • Maps HR attributes to Zendesk request fields.
  • Supports configurable rules to determine when employee lifecycle events are processed for ticket creation.
  • Sends event notifications through email.
  • Generates detailed logs, operational reports, and execution summaries.

Prerequisites

The following are the prerequisites:

  • Aquera Tenant Account: You must have a tenant account in the Aquera Admin portal. Visit https://admin.aquera.io to register for a tenant account. Contact your Aquera account manager to get Aquera tenant access.
    Note: If your organization is in the EU region, use the following URL to register: https://admin.eu.aquera.io/.
  • Configure Application Connectors in the Aquera Admin Portal: You need to configure the following application connectors in the Aquera Admin Portal:
    • UKG Ready Connector: You must configure a connector for your UKG Ready in the Aquera Admin Portal. Refer to the UKG Ready Configuration Guide for configuration details.
    • Zendesk Connector: You must configure the Zendesk connector in the Aquera Admin portal. Refer to the Zendesk Configuration Guide for details.

Integration Setup

This section explains how to configure the integration to synchronize employee lifecycle events from an HR application with Freshservice and automatically create requests for the configured lifecycle events.

Create Integration

Perform the following steps to create the integration:

  1. Log in to the Aquera Admin portal.
  2. Navigate to Integrations from the left side panel.
  3. Click Create Integration.
  4. Search for HR / ITSM - Freshservice in the search box next to the Explore Templates section and click it to create a new integration.
  5. Enter a name and a description for the integration.
  6. Click Continue.

Once created, the following tabs are displayed:

  • Overview
  • Features
  • Source
  • Service Desk
  • Operations
  • Tables
  • Schedule

Overview

The Overview tab displays general information about the integration, including its purpose and supported capabilities. It provides a high-level overview of how the integration automates employee lifecycle request creation between the UKG Ready and Zendesk.

Features

The Features tab provides an overview of the functional capabilities supported by the integration. The following section is displayed on this tab:

Service Desk Bridge

The Service Desk Bridge section controls the functional capabilities supported by the integration.

The following features are available for this integration:

  • Enable HCM Bridge: This is enabled by default to process employee lifecycle events from the configured UKG Ready connector.
  • Enable Service Desk Bridge: This is enabled by default to create and manage Zendesk requests based on employee lifecycle events.
  • Enable Employee Lifecycle: This is enabled by default to process employee lifecycle events, including onboarding, employee changes, and termination events.
  • JML Lifecycle Events: This is enabled by default to create Zendesk requests for Joiner, Mover, and Leaver (JML) lifecycle events.

Additional features displayed on this page represent capabilities supported by the integration. To learn more or enable these features, contact the Aquera Support team.

Source

The Source tab allows you to identify the UKG Ready application used by the integration and define how employee lifecycle events are processed.

The following sections are available on this tab:

  • Application settings
  • Employee Lifecycle / Filter Employees

Application Settings

The Application Settings section allows you to identify the UKG Ready application instance used by the integration. The following field is available in this section for configuration:

  • UKG Ready application instance: Select the UKG Ready application connector from which employee data and lifecycle events will be retrieved for this integration. If the required connector is not available in the list, click the refresh icon next to the field to reload the available connectors.
  • Enable advanced settings: Turn on the toggle button to configure the advanced settings for this integration. When enabled, the following field is displayed.

Advanced settings
