This guide applies to integration version 1.1.0.

Prerequisite component

  • Custom Identity Source: You must configure a custom identity source in your Okta application. For more information, refer to the Custom Identity Source Configuration section in the Okta Initial Setup Guide.

Integration Execution

The Integration Execution section allows you to manage attribute updates for the user directory and the Okta application.
  • Integration Sync Mode: Select the mode that determines which attributes are updated during integration execution. The following options are available:
    • Aquera Manage: Select this option to update the user directory attributes. The Attribute Map displays the user directory attributes.
    • Okta Manage: Select this option to update the attributes of the Custom Identity Source application configured in Okta. The Attribute Map section displays only the Okta application attributes.

Aquera Manage

Aquera Manage enables users to update the user directory attributes. When Aquera Manage is selected, the Attribute Map section displays the directory attributes.

Okta Manage

Okta Manage enables users to update the attributes of the Custom Identity Source application configured in Okta. When Okta Manage is selected, the Attribute Map section displays only the Custom Identity Source application attributes available in Okta.
To use this feature, you must first configure a Custom Identity Source in your Okta application.

Onboarding

In the Bulk Upsert section, you can create new records and update existing records. Enter a JavaScript expression in the Upsert Expression field to determine whether to perform bulk update or insert operations. 
The following are sample values:
  • SOURCE.Active === false && SOURCE.JobAssignment === "Admin Assistant (USA)" && SOURCE.WorkAssignmentJobLedgerCode!== "100200" && SOURCE.WorkAssignmentJobLedgerCode!== "100201"
  • SOURCE.Active == true || SOURCE.Active == false
  • true: Considers all users whose active attribute is set to true or false in the source application. 
  • false: Ignores the upsert operation.

Offboarding

In the Bulk Delete section, you can delete multiple records at a single time based on the JavaScript expression provided in the Delete Expression field. Enter a JavaScript expression in the Delete Expression field to determine whether the bulk delete operation should be performed.
The following are sample values:

  • SOURCE.Active === false && SOURCE.JobAssignment === "Admin Assistant (USA)" && SOURCE.WorkAssignmentJobLedgerCode!== "100200" && SOURCE.WorkAssignmentJobLedgerCode!== "100201"
  • SOURCE.Active == true || SOURCE.Active == false

In the Bulk Delete section, you can delete multiple records at a single time. Provide the JavaScript expression in the Delete Expression field, the expression determines whether to perform a bulk delete operation.

Attribute Map

Auto-Create and Map Attributes in Okta Application: 

Enable the toggle button to automatically create attributes that are missing in the Okta application. Enter a source attribute/expression for the required attribute in the Attribute Map section, click Save Changes, and click the Refresh icon. If the attribute does not exist in the Okta application, the integration automatically creates the attribute. 
Refresh the Okta page to view the newly created attribute with the attribute type Custom.

If the toggle button is disabled and a source attribute/expression is configured for an attribute that is missing in the Okta application, the integration may fail. In such cases, you must manually create the attribute in the Okta application before running the integration.

Note: This feature is visible only when Aquera Manage is selected in the Integration Sync Mode field in the Connection tab.

Known Limitations and Issues

  • User Naming Attributes, Group Management and Map Manage are not supported for Okta Manage.

  • Okta Manage will not support User Naming Attributes, Group Management and Map Manage tabs. These tabs are not displayed when Okta Manage is selected in the Integration Sync Mode field in the Connection tab.
