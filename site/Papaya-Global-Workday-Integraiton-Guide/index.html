Overview

The Aquera platform allows your organization to scale complex data management by automating data integration across resource types. Aquera's integrations facilitate the automatic provisioning, ensuring consistency across systems. It allows organizations to streamline processes, dynamically scale resources, and automate repetitive tasks, ultimately improving efficiency in managing intricate IT infrastructures and applications.

This integration automates user lifecycle management between Workday and Papaya Global. It creates, updates, and deprovisions user accounts based on workforce events such as hires, transfers, leaves, and terminations. 

The integration also supports candidate processing, identity attribute writeback, username and email generation, group assignment, reconciliation, PII masking, and provisioning monitoring.

Prerequisites

The following are the prerequisites:

  • Admin Access to Workday: You must have admin access to your Workday instance. You can visit the Workday portal to get access to a Workday instance.
  • Tenant Account in the Aquera Admin Portal: You must have a tenant account with admin access in the Aquera Admin portal. Visit https://admin.aquera.io and register to get a tenant account. Contact your Aquera account manager to get the Aquera tenant access.
    Note: If your organization is in the EU region, use the following URL to register: https://admin.eu.aquera.io/.
  • Configure Application Connectors in the Aquera Admin Portal: You need to configure the following application connectors in the Aquera Admin portal to integrate with Workday:
    • Workday: Ensure that you configure the Workday connector in the Aquera Admin portal. Refer to the Workday Configuration Guide for configuration details.
    • Papaya Global: Ensure that you configure the FTP Server connector in the Aquera Admin portal. Refer to the FTP Generic Configuration Guide for configuration details.

Integration Setup

This section details the configuration and mapping process for integrating Entra ID with Certinia. It outlines the steps to create the integration, set up integration preferences, and define how worker data is mapped from Entra ID to Certinia.

Create Integration

Perform the following steps to create the integration:

  1. Log in to the Aquera Admin portal.
  2. Navigate to Integrations from the left side panel.
  3. Click Create Integration.
  4. Select Papaya Global / Workday.
  5. Enter a name and a description for the integration.
  6. Click Continue. The Configuration page is displayed to configure the integration.

Applications

The Applications tab enables you to configure various settings required for the integration execution. 
The following sections are displayed in this tab:

  • Application Configuration
  • SFTP Configuration

Application Configuration

The Application Configuration section allows you to identify the source application instance and the target application instance used by the integration. The following field is available in this section for configuration:

  • Source application: Select the required source application you want to configure in this integration
  • Target application: Select the target application from which you want to fetch the data.

SFTP Configuration

The SFTP Configuration section allows you to configure and sync the workers data from the SFTP server. The following sections are available for configuration:

  • SFTP sync settings
  • Worker sync configuration

SFTP sync settings

This section allows you to select the required settings for the worker data sync. The following field is available in this section for configuration:

  • Enable sync worker data: Select this checkbox to configure and synchronize worker data from the CSV file.

Worker sync configuration

This section allows you to configure the CSV file path, map CSV columns, and define worker data mappings required to synchronize worker data. The following fields are available for configuration:

  • File Path: Provide the relative path or the absolute path of the CSV file on the FTP server. The file extension must also be mentioned along with the filename. If the CSV file is encrypted, the extension must be accordingly modified here.
    For example: If the file is placed in the Aquera folder in the home directory and the file name is Users.csv, then the File Path can be configured in one of the following ways:
    ./Aquera/Users.csv which is the relative path
    /FileUploads/Aquera/Users.csv which is the absolute path (from the root)
    If Users.csv file has to be placed or is available directly under the home directory, then the File Path can be configured in one of the following ways:
    ./Users.csv which is the relative path
    /FileUploads/Users.csv which is the absolute path (from the root).
    Refer to the How to obtain the file path section for more details.

How to obtain the file path

  1. Open FileZilla (or any SFTP client).
  2. Enter the following connection details. For example, enter these fields to establish the SFTP connection.
    • Hostname - sftp.aquera.io
    • Username - hanu
    • Password - Aquera@1234
    • Port - 22
  3. Click Quickconnect to establish the SFTP connection.
  4. After the connection is established, navigate to the destination folder in the Remote Site.
  5. Create a new CSV file (or select the required output file) in that folder.
  6. Copy the complete remote file path of the created file or the existing output file from the Remote Site.
  7. In the integration, navigate to the Applications tab > Worker sync configuration section and paste the path into the File Path field.
