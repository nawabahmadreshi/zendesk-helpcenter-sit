Entra ID / HSI Donesafe Integration Guide

← Back to index

This guide applies to the latest public version of the integration (version 1.1.1).

Overview

The Aquera platform allows your organization to scale complex data management by automating data integration across resource types. Aquera's integrations facilitate the automatic provisioning, ensuring consistency across systems. It allows organizations to streamline processes, dynamically scale resources, and automate repetitive tasks, ultimately improving efficiency in managing intricate IT infrastructures and applications.

In this integration, any employee created, updated, or terminated in Entra ID is automatically updated in Donesafe based on the defined schedule.

To identify user records across both systems, the integration uses the User Principal Name attribute from Entra ID  and matches it to the Email in Donesafe as a correlation attribute.

Prerequisites

The following are the prerequisites:

  • Aquera Tenant Account: You must have a tenant account in the Aquera Admin portal. Visit https://admin.aquera.io to register for a tenant account. Contact your Aquera account manager to get Aquera tenant access.
    Note: If your organization is in the EU region, use the following URL to register: https://admin.eu.aquera.io/
  • Configure Application Connectors in the Aquera Admin Portal: You need to configure the following application connectors in the Aquera Admin Portal:
    • Microsoft 365: Refer to the Microsoft 365 Configuration Guide for details.
    • Donesafe: Refer to the Donesafe Configuration Guide for details.

Integration Setup

This section outlines how the integration must be configured to push user-related data from Entra ID to Donesafe.

Create Integration

Perform the following steps to create the integration:

  1. Log in to the Aquera Admin portal.
  2. Navigate to Integrations from the left side panel.
  3. Click Create Integration.
  4. Select Entra ID / HSI Donesafe.
  5. Enter a name and a description for the integration.
  6. Select your Microsoft 365 and Donesafe connector instances.
  7. Click Continue. The Configuration page is displayed to configure the integration.

Configuration

The following sections are displayed under the Configuration tab:

Applications

The Applications section displays the source and target application connectors for the integration. This section allows you to search and update these application connectors.

Parameters

The Parameters section enables you to customize the integration settings according to your specific use case. It has the following settings:

Integration Scenarios

Configure the following integration scenario:

  • Enable User Lifecycle Management: Select this checkbox to enable user provisioning and perform incremental updates.
    Note: It is mandatory to enable this checkbox to customize the user's lifecycle management.

General Settings

Configure the following settings:

  • Enable Report-Only Mode: Select this checkbox to generate a report detailing the data changes that would happen, but without applying them.
  • Enable Full Sync: Select this checkbox to enable full sync.
  • Enable Logging: Select this checkbox to generate logs outlining data changes. When selected, the Logging section is displayed for further configuration.
  • Enable Report Generation: Select this checkbox to generate the integration report. When selected, the Reporting section is displayed for further configuration.
  • Enable Notifications: Select this checkbox to enable the integration-related notifications. When selected, the Notifications section is displayed for further configuration.
  • Enable Log Insights: Select this checkbox to visualize the integration-related metrics. When selected, the Log Insights section is displayed for further configuration.
  • Enable Debug Mode: Select to generate logs outlining data changes that would occur for debugging.

Manage User

The Manage User section allows you to define filters, conditions, limits, and user synchronisation settings that are applied during integration execution. It has the following sections:

Manage User Settings

Configure the following settings:

  • Source Filter Attribute: Select the Entra ID filter to filter users while retrieving from Entra ID. The available options are Mail and User Principal Name.
  • Source Filter Value: Enter the value of the selected source filter.
  • Create User Limit: Specify the maximum number of employee records that can be created in the target application during a single integration run.
    Note: If an inactive user is passed from the source application during an integration run, then that user will not be found in the target application and will be ignored.
  • Create Condition: Select a create condition to determine whether a user has to be created in the target application. The available options are UserType(Member), UserType(Guest), and Custom Create Condition. 
  • Custom Create Condition: Enter the JavaScript expression to create a new user in the target application. 
    Note: This field is displayed only when the Custom Create Condition is selected.
  • Update User Limit: Specify the maximum number of employee records that can be updated in the target application during a single integration run.
  • Update Condition: Select the update condition to determine whether a user has to be updated in the target application. The available options are UserType(Member), UserType(Guest), User Company Name Update Condition, User Department Update Condition, and Custom Update Condition. 
  • Custom Update Condition: Enter the JavaScript expression to update a user in the target application. 
    Note: This field is displayed only when the Custom Update Condition is selected.
  • Terminate User Limit: Specify the maximum number of employee records that can be terminated from the target application during a single integration run.
  • Terminate Condition: Select the terminate condition to determine whether a user has to be terminated in the target application. The available options are UserType(Member), UserType(Guest), User Company Name Terminate Condition, User Department Terminate Condition, and Custom Terminate Condition. 
  • Custom Terminate Condition: Enter the custom terminate condition to terminate a user in the target application. 
    Note: This field is displayed only when the Custom Terminate Condition is selected.
  • Import Limit: Specify the maximum number of employee records that can be imported from the source application during a single integration run.
  • Map Manager ID from Donesafe: Select this checkbox to retrieve the user's manager ID from Donesafe when creating and updating a user.
    Notes:
    • When a user is created in Entra ID, the manager IDs in Entra ID and Donesafe may differ, but the email ID remains the same. This checkbox uses the manager's email ID to map the manager ID from Entra ID to Donesafe.
    • If the checkbox is not selected, the integration uses the attribute mapper to verify and map the manager ID.
    • If the attribute mapper does not contain manager details, the user will be created without a manager ID.

User Correlation Settings

Configure the following user correlation settings:

  • Select Source Field for Correlation: Select the Entra ID attribute from the dropdown menu to distinctly find the associated HSI Donesafe user record. 
  • Select Target Field for Correlation: Select the HSI Donesafe attribute from the dropdown menu to distinctly find the associated Entra ID user record.

Attribute Map

The Entra ID to HSI Donesafe integration maps the Microsoft 365 and HSI Donesafe attributes. You can modify only the source attributes as needed to align with your specific use case.

You can write JavaScript expressions to modify the value of the source attribute and construct a value to be updated in the target attribute. Write the expression directly in the source attribute field or click the Expand icon in the source attribute field to write a long-expression.

All attributes marked with a red asterisk (*) indicate required fields for successful provisioning.

After the source-to-target attribute mapping is completed, click Save Changes at the top-right corner of the page to save the integration.

Update the Integration to the Latest Version

You can upgrade an integration built from a template to the latest version to access new features and enhancements. 

Perform the following steps to upgrade an integration:

  1. Navigate to the Integrations module on the Aquera Admin portal.
  2. Click the vertical ellipsis icon next to an integration and click View Details. The Details panel is displayed with the following sections:
    • INTEGRATION DETAILS: Displays the integration name, description, creation date, last update date, and the user who created or last updated it.
    • TEMPLATE DETAILS: Displays the current version number and its features under CURRENT VERSION. If a newer version is available, the version number and the changes are shown under NEW VERSION AVAILABLE with an Upgrade button.
  3. Click Upgrade. The Upgrade Integration pop-up window is displayed.
  4. Provide the following details for the new integration to be created after the upgrade:
    • New Integration Name: Enter the name of the new integration.
    • Description: Provide a description for the new integration.
      The current version number and the upgraded version number are displayed.
  5. Click Upgrade. A new integration is created with the same configuration details as the existing one, but with features or enhancements from the upgraded version.
