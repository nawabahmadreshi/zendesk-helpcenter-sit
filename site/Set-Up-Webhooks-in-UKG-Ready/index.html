Set Up Webhooks in UKG Ready

← Back to index

Overview

When a specific set of events occurs in an application or system, Aquera integrations can process those events and update those changes in a different system or application. The events can be specific data changes in the application, such as creating a new user, creating a new hire, and updating an employee's data. For the application to send those events, you must configure webhooks in the application and specify the set of events for which the notifications have to be sent. When you configure webhooks in that application, you must also specify Aquera's event integration URL to which you want to send those event notifications.

This guide explains the webhook setup in the UKG Ready application to enable the application to send events to Aquera. After the webhook setup is completed in UKG Ready, when a specific event occurs, UKG Ready sends a JSON payload containing the event details to the Aquera event integration URL configured in the webhooks. Depending on the type of event, the payload data vary. Aquera integration then processes these events and updates the corresponding data in a target application.

Prerequisites

The following are the prerequisites:

  • Make sure that you have access to Global Setup > Webhook Subscriptions.
  • Verify permissions under Profile Policies > Security > Global tab > Global Setup > Webhook Subscriptions.
  • You must set up an integration in the Aquera Admin portal to process the UKG Ready events.

Set Up Webhooks in UKG Ready

Perform the following steps to set up Webhooks in UKG Ready:

  1. Log in to your UKG Ready instance using the admin credentials.
  2. Click the hamburger menu () at the top-left corner of the page. A navigation pane is displayed on the left side of the page.
  3. Go to the Settings tab and navigate to Global Setup > Webhook Subscriptions.

    You will be redirected to the Webhook Subscriptions page.
  4. Click NEW SUBSCRIPTION.
    You will be redirected to the Available Webhooks page, where all webhooks supported by UKG Ready are displayed.
  5. Click the () icon of the webhook you want to set up. For example, click Account Status Changed.

    You will be redirected to the Add Subscription page for the selected event.
  6. Enter the following details on the Add Subscription page:
    • Name: Enter a name for the selected event category.
    • Endpoint URL: Provide the URL that you copied from the integration page in the Aquera Admin portal. For details, refer to the Obtaining Event URL and Token section.
    • SELECT AN AUTHENTICATION TYPE: Select Bearer token.
    • Token: Provide the token that you copied from the integration page in the Aquera Admin portal. For details, refer to the Obtaining Event URL and Token section.
    • Payload Fields: Select the fields that should trigger the event when any of them are updated.
  7. Click SAVE.

Click TEST CONNECTION to test the connection and verify that it is successfully established. If the configured endpoint URL and token are valid, a success message will be displayed.

Whenever any enabled event occurs, UKG Ready sends a JSON payload containing the event details to the Aquera event integration URL.

Obtaining Event URL and Token

After configuring the integration, perform the following steps to obtain the event URL and token from the integration:

  1. Navigate to the Event tab.
  2. Perform the following in the Event tab:
    • Event Trigger Enabled: Turn on this toggle button to trigger the integration when events occur in UKG Ready.
    • Event Source: Select the UKG Ready connector application that you configured for the integration from the dropdown menu.
    • URL: Copy the URL and use it when setting up the webhooks in the UKG Ready portal. Refer to the Set Up Webhooks in UKG Ready section for details.
    • Create Token: Click Create Token. A token is generated. Click Save Changes twice to save the configuration, then copy the token and use it when setting up the webhooks in the UKG Ready portal. Refer to the Set Up Webhooks in UKG Ready section for details.
