Set Up Webhooks in UKG Pro

← Back to index

Overview

When a specific set of events occurs in an application or system, Aquera integrations can process those events and update those changes in a different system or application. The events can be specific data changes in the application, such as creating a new user, creating a new hire, and updating an employee's data. For the application to send those events, you must configure webhooks in the application and specify the set of events for which the notifications have to be sent. When you configure webhooks in that application, you must also specify Aquera's event integration URL to which you want to send those event notifications.

This guide explains the webhook setup in the UKG Pro application to enable the application to send events to Aquera. After the webhooks setup is completed in UKG Pro, when a specific event occurs, UKG Pro sends a JSON payload containing the event details to the Aquera event integration URL configured in the webhooks. Depending on the type of event, the payload data vary.

Aquera integration then processes these events and updates the corresponding data in a target application.

Prerequisites

The following are the prerequisites:

  • Administrator access to the UKG Pro webhooks portal: You must have the admin credentials (username and password) of the UKG Pro webhooks portal.
  • Integration Setup: You must set up an integration in the Aquera Admin portal to process the UKG Pro events. For details, refer to the Integration Studio Guide.

Set Up Webhooks in UKG Pro

Perform the following steps to set up Webhooks in UKG Pro:

  1. Go to the UKG Pro Webhooks portal in your browser using the URL for your region.
    • For US HCM and WFM customers, enter https://webhooks.ukg.net.
    • For Canadian customers, enter https://webhooks-ca.ukg.net.
    • For WFM EU, enter https://webhooks-eu.ukg.net.
    • For WFM AU, enter https://webhooks-au.ukg.net.
  2. Enter the company access code. For details on creating the company access code, refer to the Creating Company Access Code section.
  3. Select Next.
  4. Enter your username and password.
  5. Select Sign In.
  6. Click the Add Subscription button.
  7. Enter a subscription name.
  8. Paste the URL that has been copied from the integration in the Aquera Admin portal. For details, refer to the Obtaining Event URL and Token section.
  9. (Optional) To secure the subscription, at the Add HMAC Secret field, enter an HMAC secret with a minimum of 24 characters. Be sure to record the HMAC secret. You may use the Copy icon to copy and paste it. Once you save the subscription, you cannot view or edit the HMAC secret, you can only generate a new one.
  10. (Optional) At the Add Free Form Headers fields, enter a custom header key and custom header value.
  11. (Optional) Select the Plus icon to add additional custom header keys and values, as needed.
  12. From the Available Events section, select the boxes next to the events for which you want to receive notifications.
  13. Select the right arrow icon to move the events to the Selected Events section. To remove an event from the Selected Events section, uncheck the box and select the left-facing arrow icon.
  14. (Optional) To create this subscription in an inactive state, select the Save this Subscription as Inactive box.
  15. Select Save.

The Subscription section displays the new subscription. You can update a subscription by selecting the Ellipsis icon for the associated subscription and selecting Edit. For more details, refer to the UKG Webhooks User Guide.

Note: If you need to update the HMAC secret or do not know the existing secret, enter a new secret.

Creating Company Access Code

Perform the following procedure to create the company access code:

Note: If you are a WFM-only customer, you may use a vanity URL to identify your company.

  1. Log in to the UKG Pro instance using the admin credentials.
  2. Navigate to Menu > System Configuration > System Settings > Mobile App and Chat Integrations.
  3. On the Mobile App and Chat Integrations page, select the Edit (pencil) icon.
  4. On the Edit page, enable the Enable Mobile App field and disable all other fields.
  5. Update the Company Access Code field with your company access code.
  6. Save the form.
    Note: After clicking Save, a warning that you cannot update the company access code once it has been created will appear. Acknowledge the warning and Save the form.

Once complete, this creates the Mobile App. To generate a company access code without creating the Mobile App, first perform the procedure above, then perform the following additional steps:

  1. On the Mobile App and Chat Integrations page, select the Edit (pencil) icon.
  2. On the Edit page, disable the Enable Mobile App field and leave all other fields disabled.
  3. Save the form.

Once these steps are complete, a company access code will be created without activating mobile or sending any unwanted notifications.
Notes: Enabling the Mobile App does not automatically grant access to employees. To safeguard against unintended use:

  • When enabling the Mobile App, avoid selecting options like Show Installation Instructions and Display Workspace Nickname.
  • Create the Company Access Code and share it only with your admin team.
  • In Role Administration, under each role, ensure that the Mobile Access Rights section remains unselected (which is the default).

Employees cannot use the Mobile App unless they have the Company Access Code and the appropriate permissions.

Obtaining Event URL and Token

After configuring the integration, perform the following steps to obtain the event URL and token from the integration:

  1. Navigate to the Event tab.
  2. Perform the following in the Event tab:
    • Event Trigger Enabled: Turn on the Event Trigger Enabled toggle button to trigger the integration when events occur in UKG Pro.
    • Event Source: Select the UKG Pro connector application that you configured for the integration from the dropdown menu.
    • URL: Copy the URL and paste it into the Event Subscription tab when setting up the webhooks in the UKG Pro Webhooks portal.
    • Create Token: Click Create Token. A token is generated. Click Save Changes twice to save the configuration.
