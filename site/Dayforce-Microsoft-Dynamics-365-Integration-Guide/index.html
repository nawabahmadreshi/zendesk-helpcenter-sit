Overview

Prerequisites

The following are the prerequisites:

  • Aquera Tenant Account: You must have a tenant account in the Aquera Admin portal. Visit https://admin.aquera.io and register to get a tenant account. Contact your Aquera account manager to get Aquera tenant access.
    Note: If your organization is in the EU region, use the following URL to register: https://admin.eu.aquera.io/ 
  • Configure Applications in the Aquera Admin Portal: 
    • Dayforce Connector: Ensure you add and configure the Dayforce connector in the Aquera Admin portal. For details, refer to the corresponding Dayforce Configuration Guide.

Integration Setup

Perform the following steps to create the integration:

  1. Log in to the Aquera Admin portal.
  2. Navigate to Integrations on the left panel.
  3. Click Create Integration.
  4. Search for Dayforce / Dynamics 365 in the search box next to the Explore Templates section, and click it. The Create New Integration pop-up window is displayed.
  5. Enter a name and a description for the integration.
  6. Select the source and target applications.
  7. Click Continue.

Configuration

The Configuration tab includes a list of configurations required to set up the integration. The following sections are available under this tab:

  • Applications
  • Parameters
  • Logging Settings
  • Reporting Settings
  • Notification Setting
  • Log Insights Setting

Applications

The Applications section allows you to select the Dayforce connector and the Dynamic 365 Finance connector that are used by the integration. The following fields are displayed:

  • Dayforce: Select the Dayforce application from which the integration retrieves the data.
  • Dynamic 365 Finance: Select the Dynamic 365 application from which the integration retrieves the data.

Parameters

The Parameters section allows you to configure the settings that control how the integration runs.

The Execution features section consists of the following fields:

  • Is Report Only: Enable this toggle to generate a report that shows the data that would be changed, without actually making those changes.
  • Enable Logging: Enable this toggle to configure log settings. When enabled, the Logging Settings section is displayed.
  • Enable Reporting: Enable this toggle to configure the report settings. When enabled, the Reporting Settings section is displayed.

Logging Settings

The Logging Settings section lets you set the level of details to be included in the logs. This section is displayed only when the Enable Logging toggle is enabled.

The Log Settings section consists of the following fields:

  • Select the Log Detail Level: Select the log detail level. The following are the available options:
    • Summary: Select this to include only a summary in the logs.
    • Full: Select this to include all attribute details in logs.
    • Custom: Select this option to include only the attribute details that you want in the logs. When selected, the following fields are displayed:
      • Attribute Filter: Select the option to specify which attributes must be included or excluded from the logs.
        • Inclusion List: Select this if you want to choose attributes to be included in logs. When selected, the following field is displayed:
          • Included Attributes: Enter the attributes to be included. For example, Email.
        • Exclusion List: Select this if you want to choose attributes to be excluded from the logs. When selected, the following field is displayed:
          • Excluded Attributes: Enter the attributes to be excluded. For example, FirstName.

Reporting Settings

The Reporting Settings section lets you to set the level of details to be included in reports. This section is displayed only when the Enable Reporting toggle is enabled.

The Report Settings section consists of the following fields:

  • Select the Report Detail Level: Select the report detail level. The following are the available options:
    • Summary: Select this to include only a summary in the report.
    • Full: Select this to include all attribute details in report.
    • Custom: Select this option to include only the attribute details that you want in the report. When selected, the following fields are displayed:
      • Custom Report Level: Select the option to specify which attributes must be included or excluded from the report. The following options are available:
        • Inclusion List: Select this if you want to choose attributes to be included in report. When selected, the following field is displayed:
          • Custom Report Includeds: Enter the attributes to be included. For example, Email.
        • Exclusion List: Select this if you want to choose attributes to be excluded from the report. When selected, the following field is displayed:
          • Custom Report Excluded: Enter the attributes to be excluded. For example, FirstName.
