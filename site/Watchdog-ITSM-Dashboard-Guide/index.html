Overview

When you configure Watchdog to monitor ITSM operations, it tracks the tickets generated for worker lifecycle events, including onboarding, role or organizational changes, and offboarding. It also monitors the actions performed on these tickets, such as creation, update, and deactivation.

When Watchdog runs, it processes the ITSM event data and generates a dashboard that provides visibility into ticket volumes, processing status, success rates, and lifecycle event distribution. The dashboard also groups tickets by state, department, and service catalog or request type, and displays the most recent lifecycle events and their corresponding service desk tickets.

This guide explains the ITSM dashboards generated by Watchdog and the information available in each dashboard.

ITSM Dashboard Created by Watchdog

This ITSM Dashboard generated by Watchdog provides a consolidated view of ITSM ticket activity generated for worker lifecycle events. It enables administrators to monitor the creation, processing, and status of Joiner, Mover, and Leaver (JML) tickets and verify that ITSM operations are being executed successfully.

This section explains the details available in the dashboards and provides some sample dashboards.

The ITSM dashboard includes the following details:

  • The total number of ITSM events processed during the selected time period.
  • The total number and percentage of tickets created for worker onboarding events.
  • The total number and percentage of tickets created for worker role, department, or organizational changes.
  • The total number and percentage of tickets created for worker offboarding or account deactivation.
  • The success rate of the ITSM operations, which is the percentage of ITSM operations that completed successfully.
  • The distribution of ITSM operations based on the action (Create/Update/Deactivate) performed.
  • The number of tickets grouped by their current state.
  • The number of ticket lifecycle events grouped by department.
  • The number of tickets created for each Service Catalog or request type configured in the ITSM application.
  • The most recent ITSM lifecycle events and the corresponding service desk tickets generated for user lifecycle and provisioning activities.

Detailed Logs

The Detailed Logs section provides access to the individual audit events processed by Watchdog during the selected audit period. These logs serve as the underlying data source for the dashboard metrics, policy evaluations, and compliance findings.

Each log entry includes the following information:

  • Time: The date and time when the event was processed.
  • Category: The source category of the event (for example, Directory, HR).
  • EventType: The operation performed, such as Create, Read, Update, Deactivate, or Delete.
  • Lifecycle Phase: The user lifecycle stage associated with the event, such as Provisioning, Mover,  Leaver.
