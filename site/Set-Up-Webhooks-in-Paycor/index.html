Set Up Webhooks in Paycor

← Back to index

Overview

When a specific set of events occurs in an application or system, Aquera integrations can process those events and update those changes in a different system or application. The events can be specific data changes in the application, such as creating a new user, creating a new hire, and updating an employee's data. For the application to send those events, you must configure webhooks in the application and specify the set of events for which the notifications have to be sent. When you configure webhooks in that application, you must also specify Aquera's event integration URL to which you want to send those event notifications.

This guide explains the webhook setup in the Paycor application to enable the application to send events to Aquera. After the webhooks setup is completed in Paycor, when a specific event occurs, Paycor sends a JSON payload containing the event details to the Aquera event integration URL configured in the webhooks. Depending on the type of event, the payload data vary.

Aquera integration then processes these events and updates the corresponding data in a target application.

Prerequisite

You must set up an integration in the Aquera Admin portal to process the Paycor events. For details, refer to the Integration Using Scripts guide.

Set Up Webhooks in Paycor

Perform the following steps to set up Webhooks in Paycor:

  1. Log in to your Paycor developer portal using the admin credentials.
  2. Click Applications on the top menu bar.
  3. Scroll down to the Applications section and click +Application to create an application. 
  4. Create an application, assign the required scopes, and activate the application. For details, refer to the Creating Application, Configuring Application, and Activating Application sections in the Paycor Initial Setup Guide.
  5. Go to the Event Subscription tab and enter the following details:
    • Event Notification URL: Paste the URL that has been copied from the integration in the Aquera Admin portal. For details, refer to the Obtaining Event URL and Token section.
    • Event Secret: Paste the token that has been copied from the integration in the Aquera Admin portal. For details, refer to the Obtaining Event URL and Token section.

      Note: Make sure the events are subscribed before you activate the application. If events are subscribed after the application activation process, you must re-activate the application.
  6. Enable the required events to trigger an action when the corresponding fields are updated in the Paycor application, then click Save.

    Whenever any of the enabled events occur, Paycor sends a JSON payload with the event details to the Aquera event integration URL. Based on the scopes enabled in the Data Access tab, the events will be listed in the Events Subscription tab.

    For example, to capture updates to an employee’s termination, you must enable the Employee Information Updated event.

    Refer to Event Triggers for more details about the specific events.
  7. You must generate a refresh token and configure it as a bearer token for authentication to receive the JSON payload with the event details to the Aquera event integration URL. For details on generating the refresh token, refer to the Activating Application section in the Paycor Initial Setup Guide.
    Note:

Obtaining Event URL and Token

After configuring the integration, perform the following steps to obtain the event URL and token from the integration:

  1. Navigate to the Event tab.
  2. Perform the following in the Event tab:
    • Event Trigger Enabled: Turn on the Event Trigger Enabled toggle button to trigger the integration when events occur in Paycor.
    • Event Source: Select the Paycor connector application that you configured for the integration from the dropdown menu.
    • URL: Copy the URL and paste it into the Event Subscription tab when setting up the webhooks in the Paycor developer portal.
    • Create Token: Click Create Token. A token is generated. Click Save Changes twice to save the configuration, then copy the token and paste it into the Event Subscription tab when setting up webhooks in the Paycor developer portal.
