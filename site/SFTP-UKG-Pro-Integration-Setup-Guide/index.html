SFTP / UKG Pro Integration Setup Guide

← Back to index

Overview

The Aquera platform enables your organization to scale complex data management by automating data integration across various resource types. Aquera's integrations facilitate automatic provisioning, ensuring consistency across systems. It enables organizations to streamline processes, dynamically scale resources, and automate repetitive tasks, ultimately enhancing efficiency in managing complex IT infrastructures and applications.

This integration retrieves employee data from UKG Pro, generates a file, and delivers it to the configured SFTP directory.

The integration can run in full or incremental synchronization mode. It also supports user filtering, debug execution, report-only execution, configurable file formats, timestamped filenames, logs, reports, notifications, and Log Insights.

Key Functions

The SFTP / UKG Pro integration performs the following functions:

  • Retrieves employee data from UKG Pro and generates a file in a specific SFTP location.
  • Supports full synchronization and incremental synchronization. Full synchronization processes all employees that match the configured user filter, while incremental synchronization processes employees changed since the last sync.
  • Generates detailed logs and reports.
  • Sends email notifications for successful, failed, and skipped integration executions.

Integration Setup

This section outlines how to create and configure the integration to generate employee files in SFTP from UKG Pro data.

Create Integration

Perform the following steps to create the integration:

  1. Log in to the Aquera Admin portal.
  2. Navigate to Integrations from the left-side panel.
  3. Click Create Integration.
  4. Search for SFTP / UKG Pro in the search box next to the Explore Templates section, and then select it to create a new integration.
  5. Enter a name and a description for the integration.
  6. Select your UKG Pro and FTP Generic connector instances.
  7. Click Continue. The Configuration page is displayed.

Configuration

The following sections are displayed under the Configuration tab:

Applications

The Applications section displays the UKG Pro and FTP Generic application connectors that you have selected for the integration. This section allows you to search and update these application connectors.

Parameters

The Parameters section enables you to customize the integration features and settings according to your use case. It has the following settings:

Integration Settings

Enable the following features based on your requirements:

  • Report Only / Enable report-only mode: Enable this to generate the output file and integration report without uploading the file to SFTP.
  • Enable UKG Core PRO User Full Sync / Enable full sync: Enable this to include all UKG Pro employee records that match the configured user filter for processing during each run.
  • Enable UKG Core PRO User Incremental Sync / Enable incremental sync: Enable this to execute the integration in incremental mode. In incremental mode, the integration retrieves and processes only the employee data that have been added or modified in UKG Pro since the last integration execution.
    Note: If both full and incremental synchronization are enabled, incremental synchronization takes precedence.
  • Debug Mode / Enable debug mode: Enable this to test the integration for specific UKG Pro employees. When enabled, the Debug Settings section is displayed for further configuration.
    Note: If this field is enabled and full or incremental sync is also enabled, debug mode takes precedence.

Debug Settings

This section enables you to customize the debug mode settings.

Note: This section appears only if you have selected the Debug Mode / Enable Debug Mode setting.

It has the following settings:

  • Select Field For Debugging / Select field to filter employees for debugging: Select Employee ID or Email Address to filter the UKG Pro employees for the debug run.
  • Employee IDs: Enter one or more comma-separated employee IDs to identify UKG Pro employees for the debug run.
    Note: This field is displayed only when Employee ID is selected to filter employees.
  • Email Addresses: Enter one or more comma-separated email addresses to identify UKG Pro employees for the debug run.
    Note: This field is displayed only when Email Address is selected to filter employees.

General Settings

Configure the following general settings:

  • Enable Logging: Select this to generate logs outlining data changes. When enabled, the Log Settings section is displayed for further configuration.
  • Enable Notifications: Select this to enable integration-related notifications. When enabled, the Notifications section is displayed for further configuration.
  • Enable Report Generation: Select this to generate the integration report. When enabled, the Report Settings section is displayed for further configuration.
  • Enable Log Insights: Select this to visualize the integration-related metrics. When enabled, the Log Insights section is displayed for further configuration.

UKG to SAP Settings / Applications Setting / UKG to SFTP Settings

This tab enables you to control which UKG Pro users are included and how the files are generated in SFTP.

UKG Pro Settings

  • Users To Be Fetched / Employees to be included: Select the UKG Pro employees to be included in the integration. You can select all users, one status, a supported combination of statuses, or Custom.
    For example:
    • Select All Active Users to include only employees whose account status is active.
    • Select Custom to define a custom filter.
  • Enter Custom Filter: Enter an expression that identifies the employees to include. The expression is evaluated for each employment record. Use = for equals and the words and/or to combine conditions.
    Notes:
    • This field is displayed only when Custom is selected in the Users To Be Fetched / Employees to be included field.
    • In an expression, use A for Active, T for Terminated, and L for Leave of Absence.
  • Timezone Location Field / Timezone: Use this field to identify the employee’s US state or Canadian province to determine the applicable time zone. The integration uses this value to determine the time zone when evaluating date and time expressions provided in custom filter and future hire hold condition.
  • Manage future hires: Enable this to exclude active employees whose hire date is in the future from the current output file. These employees are excluded from the current file and reevaluated based on the Future Hire Hold Condition during subsequent incremental synchronization runs.
    Note: This setting applies only to incremental synchronization.
  • Future hire hold condition: Enter an expression that identifies the future hires.

SFTP Settings

  • Select The Directory: Select Working Directory to upload the file to the working directory configured in the SFTP server, or select Custom Input to provide another directory. If you select Custom Input, the following field is displayed:
    • SFTP Directory: Enter the target directory on the SFTP server. Enter ./ to use the connection working directory. To deliver the same file to multiple custom directories, enter the directory paths separated by commas. This field is required when Custom Input is selected.
  • SFTP file name: Provide a name for the file to be generated on the SFTP server.
    Note: The selected file-format extension is applied automatically.
  • Generate a unique file name by appending timestamp: Enable this to append a run timestamp to the filename. For example, filename_YYYY-MM-DD_HH-MM-SS.csv.
    Note: This prevents earlier files from being overwritten.
  • File format: Select the format of the file to be generated. You can select TXT, TSV, or CSV.
    Note: CSV files are comma-delimited and include a header row. TXT and TSV files are tab-delimited and do not include a header row. The selected file-format extension is applied automatically.

Attribute Map

The Attribute Map tab enables you to define how UKG Pro attributes are mapped when generating the file on the SFTP server.

UKG Pro attributes are listed on the left, and the target file columns appear on the right for mapping based on your specific use case.

You can use JavaScript expressions to transform source attribute values and construct the values that are updated in the file. You can enter the expression directly in the source attribute field or click the expand icon to write a longer expression.

The Search Attributes field allows you to filter the list of available attributes for mapping.
After the source-to-target attribute mapping is completed, click Save Changes at the top-right corner of the page to save the configuration.

Tables

The Tables tab enables you to define custom values that are not available from UKG Pro. After creating a table, reference it in an attribute-mapping expression to populate values in the generated file.

Refer to the Using Tables in Integrations guide for more details.
